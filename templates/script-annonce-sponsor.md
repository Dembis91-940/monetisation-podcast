# Template — Script d'annonce sponsor à l'antenne

> **Quand l'utiliser** : les intégrations sponsor que vous lisez dans vos épisodes. Personnalisez le milieu de chaque script avec votre expérience réelle. 60-90 secondes à voix lente = 150-220 mots.

---

## Pré-roll (15-30 s) — en début d'épisode

« Avant de commencer, 30 secondes pour [Nom de la marque]. [Une phrase sur ce que c'est]. J'utilise [leur produit] depuis [durée], et honnêtement [votre vraie expérience en une phrase]. Si ça vous intéresse, code promo **[CODE]** sur [site], [XX] % de réduction. On en reparle en fin d'épisode. C'est parti. »

## Mid-roll (60-90 s) — le format principal

« Petite pause pour vous parler de [Nom de la marque]. Vous savez que je ne recommande que ce que j'utilise vraiment. Alors [Nom de la marque], c'est [description simple, 2 phrases]. Moi ce que j'aime, c'est [2 arguments concrets + 1 anecdote personnelle : quand/qu'il m'a servi].

Ce qui est intéressant pour vous : [bénéfice auditeur : économie, gain de temps, résultat]. Si vous voulez tester, le code **[CODE]** vous donne [avantage] sur [site]. Ce code marche jusqu'au [date]. Et si vous le prenez, écrivez-moi : j'aimerais savoir ce que vous en pensez. »

## Post-roll (15-20 s) — en fin d'épisode

« Merci d'être allés au bout. Et merci à [Nom de la marque] de soutenir le podcast : c'est grâce à eux que ce contenu reste gratuit. Si vous voulez les soutenir à votre tour, code **[CODE]**, lien dans les notes. À la semaine prochaine. »

---

## Règles d'or

1. **Testez avant de recommander.** Une intégration sincère convertit 5× mieux qu'une lecture de communiqué.
2. **Un seul message par intégration** : le produit, le code, la date limite. Pas plus.
3. **Séparez nettement** la publicité du contenu (« petite pause pour vous parler de… ») : vos auditeurs vous feront confiance plus longtemps.
4. **Annoncez toujours une date limite** pour le code : ça crée l'urgence.
5. Enregistrez l'intégration au même moment que l'épisode, dans la même prise de voix — pas de changement de ton qui sonne « pub ».
